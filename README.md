# e-plantShopping

Welcome to **e-plantShopping**, an elegant and responsive React web application designed for plant enthusiasts! 

## Project Overview
This application provides a seamless shopping experience for users to browse through a diverse collection of houseplants, view detailed care information, add beautiful greenery to their shopping carts, and manage their orders effortlessly.

## Key Features
* **Product Catalog:** Browse various categories of plants (Air Purifying, Aromatic, etc.).
* **Interactive Cart:** Add, remove, or update the quantities of items dynamically.
* **Responsive Layout:** Optimized beautifully for both mobile and desktop screens built with React and Vite.
